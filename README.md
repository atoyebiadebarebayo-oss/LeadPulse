# LeadPulse — High-Converting Landing Page & Lead Gen Engine

LeadPulse is a sleek, modern lead generation platform engineered for digital agencies and service businesses. It features an interactive real-time cost estimator, dynamic package configuration, direct WhatsApp quote routing, and lead capture persistence.

Explore the live application here:[https://leadpulses.netlify.app]

## ✨ Features

- **Interactive Instant Quote Calculator**: Automatically calculates project costs and business-day turnaround times based on selected base packages and add-on services.
- **WhatsApp Quote Router**: Formats calculated estimate summaries directly into instant pre-filled WhatsApp messages for quick conversion.
- **Lead Capture & Local Storage**: Stores incoming client lead submissions locally in `localStorage`.
- **Strategy Call Modal**: Interactive popup lead capture form for scheduling client strategy sessions.
- **Dark/Light Mode Engine**: Seamless theme toggling with local storage persistence.
- **Ultra-Responsive Layout**: Optimized for mobile, tablet, and desktop viewports.
